## Decisions

- 2026-10-26: Fixture masking (IMP-21). XLSX: only text nodes of `sharedStrings.xml` / pivot cache / one sheet edited in place, every other zip entry byte-identical. PDF: true redaction plus text redrawn in Helvetica at the same baseline, scaled to the original width. Unmasked words keep their exact coordinates. The real→fictitious mapping lived only in a temporary directory and was deleted. Originals stay outside the repository.
- 2026-10-26: Fixture names follow POR-04 (`itau-closed-bill-2026-10.pdf`, `itau-open-bill-2026-11.xlsx`, `monthly-workbook-model-2026-11.xlsx`).
- 2026-10-26: By user choice, the barcode / digitable line, card finals and file metadata were kept (none of the metadata had personal names). The model's `MÃE` sheet keeps its name (role, cited by XLS-06).
- 2026-10-26: Stack upgraded from SPEC §12 by user decision (Q1): Java 25 LTS (Temurin, enforced by maven-enforcer), Spring Boot 4.1 (Jackson 3, Spring HATEOAS 3), React 19. The SPEC text still says Java 21 / Boot 3 / React 18 until the user edits it.
- 2026-10-26: Git is local only (Q2); CI workflows are written and run locally where possible.
- 2026-10-26: Session token travels in the `X-Session-Token` header, read from `APP_SESSION_TOKEN`; `/actuator/health` and CORS preflight need no token (IMP-04). Allowed origins: `tauri://localhost`, `http(s)://tauri.localhost`, Vite dev server.
- 2026-10-26: Single-instance lock (POR-10) lives in the backend; it exits with code 10 (held by a running process) or 11 (orphaned). The shell turns 11 into a confirmation dialog and relaunches with `--app.lock.force=true`.
- 2026-10-26: POR-03 leftovers for the launcher (POR-08): start the JVM with `-Djava.io.tmpdir=<app>/data/tmp`, because sqlite-jdbc extracts its native library to the JVM temp dir. Tomcat and multipart temp dirs are already under `data/tmp`.
- 2026-10-26: The shell passes its PID (`--app.parent-pid`); the backend closes itself cleanly if the shell dies (POR-08), so a crash never leaves the database locked.
- 2026-10-26: The shell stops the backend with `POST /actuator/shutdown` (token required) on both OSes instead of OS signals; the token now guards every path except health and CORS preflight.
- 2026-10-26: Linux shell sets `WEBKIT_DISABLE_DMABUF_RENDERER=1` unless already set: WebKitGTK showed "Failed to create GBM buffer" (blank window risk) on the dev machine.
- 2026-10-26: Generated Orval code is not committed; it is regenerated from `frontend/openapi/openapi.json` before build, typecheck and tests. TypeScript pinned to 6.0.x because typescript-eslint does not support 7.x yet.
- 2026-10-26: Minimal JRE built from `jdeps` on the fat jar plus locale/zipfs/crypto/DNS modules (18 modules, 76 MB on Linux); portable folder for Linux is 151 MB.
- 2026-10-26: Until the AppImage step (IMP-42), the Linux shell ships as the plain `PlanejamentoMensal` binary.
- 2026-10-26: Backend default language is pt-BR; `Accept-Language` picks pt-BR or en-US (I18N-06).
- 2026-10-26: **Adopted defaults for open questions** (user asked to implement to the end without pausing; each can be revised later, and the affected items say so):
  - Q3: an additional card is its own `Card` with `primaryCardId`; its entries belong to the primary card's `CardBill`, and RN-10/RN-19 keys use the primary card.
  - Q4: an exact `installmentKey`/`purchaseKey` is stored for idempotence (RF-73); classification uses the tolerant RN-19 match.
  - Q5: XLSX IOF lines become entries linked through `BillEntry.relatedEntryId`; the PDF "Repasse de IOF" is one bill-level IOF entry; XLSX IOF lines not matched by the closed PDF become UNCONFIRMED.
  - Q6: a card bill total sums CONFIRMED and PROJECTED entries; UNCONFIRMED entries are left out of totals and listed for review.
  - Q7: only the latest confirmed batch of a card can be undone; otherwise 409.
  - Q8: any number of MAIN members; income total = MAIN incomes + third-party reimbursements (their share of expenses); expense total = fixed + variable + card bills; the payer of a card for RF-27 is the primary card's default member.
  - Q9: SMTP password encrypted with AES-GCM and a key file in `data/` (obfuscation; documented in the settings screen).
  - Q10: the default workbook model is the masked model fixture with data rows removed, versioned as an app resource.
  - Q11: pivot table built with Apache POI's `XSSFPivotTable`, refreshed on open.
  - Q12: entries missing from a re-imported open bill become UNCONFIRMED (nothing is deleted).
  - Q13: Windows x64 and Linux x86_64 only. Q15: extra sidebar entries as built. Q16: entities/fields added as proposed. Q17: XLS-01 file name for files the user saves; POR-04 names for files kept in `data/`.
